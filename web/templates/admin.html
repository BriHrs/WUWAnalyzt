Tahap 2: Preprocessing (Pembersihan Data)

Pada tahap ini, data teks mentah dibersihkan agar siap diolah oleh model. Proses ini menggunakan fungsi preprocess_text yang mencakup Case Folding, Cleansing (Hapus URL, Mention, Hashtag, Angka, Tanda Baca), Demojize (Ekstraksi Makna Emoji), dan Normalisasi Kata (Slang).

⚙️ Lihat Detail Code Python (Logika Pembersihan) ▼ 
def preprocess_text(text):
    if not isinstance(text, str): return ""
    text = text.lower()

    # 1. Menghapus URL, Mention, Hashtag, dan Angka
    text = re.sub(r'http\S+|www\S+|https\S+', '', text, flags=re.MULTILINE)
    text = re.sub(r'\@\w+|\#', '', text)
    text = re.sub(r'\d+', '', text)

    # 2. Demojize (Ekstraksi makna emoji ke teks Indonesia)
    text = emoji.demojize(text, language='id')
    text = text.replace(':', ' ').replace('_', ' ')

    # 3. Ganti SEMUA tanda baca dengan spasi
    text = re.sub(r'[^\w\s]', ' ', text)

    # 4. Normalisasi kata (Kamus Slang)
    words = text.split()
    normalized_words = []
    for word in words:
        if word in KAMUS_SLANG_GABUNGAN:
            normalized_words.append(KAMUS_SLANG_GABUNGAN[word])
        else:
            normalized_words.append(word)

    text = " ".join(normalized_words)
    return re.sub(r'\s+', ' ', text).strip()

Tahap 3: Pembagian Data

Dataset dibagi menjadi 3 bagian menggunakan metode Stratified Holdout Split dengan rasio 80% : 10% : 10%.

Parameter stratify=Sentimen memastikan proporsi kelas Positif & Negatif tetap seimbang di setiap bagian. Total data setelah preprocessing: 2.652 baris.

Tahap 4: Hyperparameter Tuning

Grid Search dengan 40 skenario pada setiap metode split. Kombinasi: Epoch (2–5) × Learning Rate (1e-5 s.d. 5e-5) × Batch Size (16, 32).
